# How we keep this

Pocock’s move: one public repo, small files, same voice, updated on a cadence. Not a course platform. Not a dump.

## Cadence

| When | What |
| --- | --- |
| Every day | Stage, do not post. Look at `/voice`. |
| Every week | One issue note in `issues/`. One new short script. |
| Every batch | Twenty thoughts, scanner clean. |
| Never | A thousand files in one night. An X API. A secret. |

## File law

- Tip files stay short. Headline, story, when / what / how, use-when.
- Shorts stay under 80 words. One move. One still.
- Issues are a table of what actually shipped.

## Voice law

Deadpan. Sport. Fog. AI is a spotter.
If it sounds like LinkedIn, delete it.
If it sounds like a brand partnership with a skate mag, delete it. Homage is energy. Their name is not our name.

## You

Drew films. Drew composes. The repo holds the script and the tip.
