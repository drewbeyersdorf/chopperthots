# If the shop dies, the door still opens.

i have watched clever rooms go dark. the clipboard on the tank still takes the name. that’s the only kindness i trust.

## When

A node is down. Someone wants a new dependency. Someone wants the form to wait on the factory.

## What

Fail closed. Manual always works. Extra plugs stay off.

## How

The model reaches before you add a wire. The intake does not wait on the clever part.

## Use when

Outage. A new webhook. “Just make them wait.”

If the factory dies, the form still takes the row.
