# The spec goes. The form stays.

i do not mail them the whole drunk night. i mail the one page that can be built. if the shop is dark the page waits on my table. that’s a ticket, not a prayer.

## When

A human already said this is a build.

## What

A standalone spec. Inputs. Done looks like. Constraints. Not the raw intake.

## How

You send the spec to the room that builds. If that room is down, the spec stays on your desk.

## Use when

Type is build. Spec is confirmed. Someone says “just forward the form.”

Never send the seven fields. Never send an admin walk to the factory.
