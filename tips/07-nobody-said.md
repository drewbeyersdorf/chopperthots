# If nobody said it, you don’t write it.

filling the blank is how friday gets drunk. i have been that drunk. the empty cell is the last true thing in the book.

## When

A spec. A number. A name. A type. Anything that looks better when invented.

## What

Blank is valid. Unsure is valid. A guess is not.

## How

The model should reach for this without being asked. A human ritual may call it. Nobody gets to “just fill it in.”

## Use when

Two numbers disagree. A cell is empty. Someone says ship it anyway.

If the source did not say it, you do not write it.
