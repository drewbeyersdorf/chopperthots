# Not a Tuesday invention

People keep talking about agent factories like they showed up last week.

Hitachi put the word factory on a software door in 1969. Conway’s Life is 1970. The loop itself is 1940s work. Wiener. Then von Neumann wanting a machine that could make a machine. Then Ulam telling him to stop building a factory in equations and use a grid.

Those are two streams. They rhyme. They are not father and son. Life is not Hitachi. What they share is a small rule, repeated, until a shop appears.

I use the machines. I don’t let them take the wave. If nobody measured it, I don’t write it. Empty is fine. Guessing is how Friday gets stupid.

One nest. One job. You start feeding extras, you get a pile that doesn’t hunt.

Types live upstairs. Goo stays in the bottom drawer. Don’t promote the goo so the night feels done.

This is the long version. The short versions go to X and a 16 second clip. LinkedIn gets a paragraph. This page is the desk. Not Medium. Medium is rented. If it belongs to me it lives here, then maybe on drewbeyersdorf.com when that site grows a notes section.
