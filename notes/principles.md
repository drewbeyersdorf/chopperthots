# Steal the discipline, not the brand

Public. No plant IDs. No unofficial verbs.

**One first principle.** You cannot act correctly on what you cannot name, type, constrain, and audit.

HACCP independently discovered the same shape (1959–71). Palantir closed it in steel. A kitchen that still allows "just this once" has a dashboard, not a shop.

## Portable

1. Identity is a typed path.
2. One IDL, many languages; wire-verify.
3. Mutation is a closed, preconditioned, audited verb list. Humans and agents share it.
4. Observation is labeled (safe / unsafe).
5. Writes that touch two objects are one transaction.
6. Policy is data that can refuse.
7. Health is an enum with reasons.
8. The UI is a projection of object + action, not a separate app.
9. Pipelines clean; the ontology operates. Do not invert.
10. Agents last.

## Fourfold

Data, logic, action, security. If any fold is missing you have a lake, an opinion, a dashboard, or a leak.

## HACCP map

Hazard analysis → distinguish. CCP → choke-point verb. Critical limit → submission criteria. Monitor → typed observation. Corrective action → Hold. Verify → policy that can refuse. Record → if it is not named, it did not happen.

## Do not steal from GitHub Palantir

The action engine, the store, the markings. They opened the SDK. They kept the world. Anyone claiming to run Palantir from the public org is running a design system.

The model does not get a new verb.
