# How a tip gets in

Write the headline first. Then the story. Then when / what / how.

## Never commit

- API keys, tokens, passwords, `.env`
- Webhook URLs, sheet ids, Drive folders, work emails
- Hours, lb, pcs, SKUs, stop counts
- Private factory names used as if they were public products
- A script that posts to X

If you have to ask, it stays out.

## Slow

Twenty thoughts in a batch. Not a thousand files on day one.
The working set can be large. The publish is small.

## Voice

Lowercase is fine. Inventing a number is not.
